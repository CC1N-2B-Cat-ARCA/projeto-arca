# Requesitos 

Para este projeto vamos precisar que esta API seja capaz de: 

- ### Conectar ao banco de dados Postgres
- ### Conectar ao frontend
- ### Ser capaz de acessar, pesquisar, inserir, remover e atualizar o banco
- ### Ser capaz de validar cadastro e login
- ### Permitir pesquisa por animal cadastrado para adoção
- ### emitir notificações
